# OPEN-538: api-v3 imports its bill-version rules (openstates.utils.version_ordering) from DDP's
# openstates-core fork, the module the archiver and recompute-diff-order use, instead of
# carrying a copy. The fork replaces the PyPI `openstates` that poetry.lock installs.
#
# Installed after `poetry install` by the Dockerfile, deploy/Dockerfile.ddp (ddp-open-states)
# and CI:
#   pip install --no-deps --ignore-requires-python -r ddp-openstates-core.txt
# --no-deps: api-v3's own locked dependencies stay as they are.
# --ignore-requires-python: the fork declares Python ^3.13 (OPEN-515); api-v3 runs 3.9, and the
#   three modules api-v3 imports (utils.version_ordering, utils.transformers, metadata) are
#   tested here on 3.9 (api/tests/test_open538_core_version_ordering.py).
#
# To take a newer rule from core: change the commit below (a full SHA on the fork's main), then
# run the api-v3 suite and rebuild both api-v3 copies (Mac :8002 and EC2).
